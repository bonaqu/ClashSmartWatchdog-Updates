# Clash Smart Watchdog — обновления

Здесь публикуются установочные архивы и обновления программы **Clash Smart Watchdog**. Этот репозиторий используется программой для проверки новых версий; основной репозиторий разработки закрыт.

**Программа подходит не всем.** Она предназначена для настроенной связки Clash Verge Rev / Mihomo и управления совместимыми Smart-группами. Это не VPN-сервис: подписка, серверы и доступ в интернет в комплект не входят. Готовые файлы правил и DNS в архиве — примеры для определённой конфигурации; они могут не подходить вашей подписке и сети.

Если вы не понимаете, что делает программа, как настроен ваш Clash или зачем вам эти файлы, **не устанавливайте их и не меняйте конфигурацию**. Сначала разберитесь в настройках или обратитесь к тому, кто их настраивал.

## Установка и обновление

1. Откройте [последний выпуск](https://github.com/bonaqu/ClashSmartWatchdog-Updates/releases/latest), скачайте ZIP и полностью распакуйте его.
2. Запустите `START_HERE.cmd` и следуйте сообщениям установщика. Для сборки потребуется интернет; при необходимости установщик предложит подготовить .NET SDK.
3. Если Clash уже настроен, сохраняйте свои правила и DNS. Перед самостоятельным изменением конфигурации создайте её копию и внимательно читайте запросы установщика.

В установленной программе обновление можно проверить в **«Помощь → Проверить обновления»**. Автоматическая проверка по умолчанию отключена; автоматической установки нет. До запуска установщика программа проверяет скачанный архив по размеру, SHA256 и списку файлов. SHA256 подтверждает целостность файла относительно данных GitHub и не является отдельной цифровой подписью издателя.

При проблемах читайте `README_FINAL_RU.md` внутри архива и сохраняйте журнал установки. Не публикуйте ссылки на подписку, ключи, пароли или другие личные данные.
